Help Centre

Answers to common questions about buying, selling, and deliveries on CropMarket.

How do I place an order? +
Browse Shop Crops, add items to your cart, and complete checkout with Mobile Money or card.
How do I register as a farmer? +
Create a farmer account, then use the dashboard to list crops with photos and prices.
How do I use the Django backend? +
From the backend folder run python manage.py runserver, then open 127.0.0.1:8000. Demo accounts: buyer@demo.com or farmer@demo.com, password 123456.
What is the promo code FRESH10? +
Enter FRESH10 on the cart page for 10% off your subtotal (demo promotion).
